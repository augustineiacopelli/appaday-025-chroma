# 025 · Chroma — Color Palette Extractor

**App a Day · Day 025 · Utility**

Extract a full set of color palettes from any input color. Five ways to enter a color, seven palette sections generated instantly, every hex value click-to-copy, and a one-tap email to send your palette anywhere.

## What It Does

Enter any color via five input modes and generate:

- Complementary
- Analogous
- Triadic
- Split-Complementary
- Tetradic
- Tints (5 lighter values)
- Shades (5 darker values)

All five input modes stay synced in real time. A live preview swatch updates as you adjust any control.

## Input Modes

- **HEX** — type or paste any 6-character hex code (with or without #)
- **RGB** — number fields + live sliders for R, G, and B channels
- **HSL** — number fields + live sliders for Hue, Saturation, and Lightness
- **Picker** — native browser color wheel
- **Photo** — take a photo or upload an image; drag a crosshair over any pixel to sample its color in real time

## How to Use

1. Choose an input mode and enter your color
2. Press **Generate** to extract all palettes
3. Click any swatch or hex chip to copy that color to clipboard
4. Tap **✉ Email This Palette** to open your mail app with all palettes pre-filled
