# 025 · Chroma — Color Palette Extractor

**App a Day · Day 025 · Utility**

Extract a full set of color palettes from any input color. Choose your color via HEX text entry, RGB sliders, HSL sliders, or a native browser color picker — all four modes stay in sync in real time.

## What It Does

Enter any color and generate seven palette sections instantly:

- Complementary
- Analogous
- Triadic
- Split-Complementary
- Tetradic
- Tints (5 lighter values)
- Shades (5 darker values)

Every swatch and hex chip is click-to-copy. The base color info panel displays Hex, RGB, and HSL values for the selected color.

## How to Use

1. Choose an input mode: HEX, RGB, HSL, or Picker
2. Enter or adjust your color — the live preview updates immediately
3. Press **Generate** to extract all palettes
4. Click any swatch or hex chip to copy that color to your clipboard
